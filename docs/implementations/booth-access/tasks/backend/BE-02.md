# BE-02: Report-bound event link and redemption

| Field | Value |
|---|---|
| Domain / size | Backend / L |
| Wave / stream | 1 / B |
| Dependency | BE-01 |

## Problem and objective

The current `/auth/sharelink` grant is based on an email domain and lasts seven days. Blindly extending it would grant more than one report and still reject some personal registration addresses. Design and implement a separately scoped event link that cannot open another company report, without changing ordinary customer sign-in or existing share links.

## Read first and follow

- `workers/cloudflare/cug-adobe-oauth-worker/src/session.js:120-182,202-245`: signed session and link token conventions.
- `workers/cloudflare/cug-adobe-oauth-worker/src/index.js:236-297`: token redemption before CUG check.
- `workers/cloudflare/cug-adobe-oauth-worker/src/cug.js:26-97`: report access enforcement.
- `workers/cloudflare/cug-adobe-oauth-worker/src/sharelink.js:170-218`: existing domain grant, to preserve.
- `workers/cloudflare/cug-adobe-oauth-worker/test/session.test.js` and `test/cug.test.js`: time, authorization and test patterns.
- `docs/implementations/booth-access/context/target-design.md`: approved link/expiry contract.

## Files and ownership

Modify `src/session.js`, `src/index.js`, `src/cug.js`; extend `test/session.test.js`, `test/cug.test.js` and `test/index.test.js`. If code size warrants, create `src/booth-link.js` and `test/booth-link.test.js`. These Worker files are **not** concurrently edited by BE-01 or BE-03.

## Deliverables

1. Signed event-purpose token contains only the approved event/report binding and intended recipient; expiry follows approved event policy, not global `SHARE_LINK_TTL`.
2. Redemption establishes authorization for **only** the exact report path (and its required page assets) without leaking a customer-domain or staff-wide group to other reports. Invalid, expired, disabled or revoked grants fail closed.
3. Existing magic links, share links, OAuth and generic staff sessions retain their present behavior.
4. Tests prove cross-report and cross-event denial, recipient/path tampering rejection, TTL, revocation and happy path.

## Verification and done

Run `cd workers/cloudflare/cug-adobe-oauth-worker && npx vitest run test/session.test.js test/cug.test.js test/index.test.js`; if `test/booth-link.test.js` was created, run it with the same Vitest command. Then run `npx eslint src/session.js src/index.js src/cug.js test/session.test.js test/cug.test.js test/index.test.js` and `git diff --check`. Do not solve this by granting a broad account domain to an unverified bearer link.

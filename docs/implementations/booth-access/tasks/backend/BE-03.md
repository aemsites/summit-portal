# BE-03: Deliver the matched report by email

| Field | Value |
|---|---|
| Domain / size | Backend / M |
| Wave / stream | 1 / B |
| Dependency | BE-02 |

## Problem and objective

The finish action must send the **already matched** report to the attendee's registered inbox. The browser cannot supply an arbitrary recipient or path, and success cannot be reported if delivery fails.

## Read first and follow

- `workers/cloudflare/cug-adobe-oauth-worker/src/booth.js` and `test/booth.test.js` (created by BE-01).
- `workers/cloudflare/cug-adobe-oauth-worker/src/sharelink.js:190-266`: scoped mint/email/error flow to adapt, not bypass.
- `workers/cloudflare/cug-adobe-oauth-worker/src/notification.js`: mail transport and templates.
- `workers/cloudflare/cug-adobe-oauth-worker/src/index.js:133-163`: route dispatch.
- `docs/implementations/booth-access/context/target-design.md`: final approved email policy.

## Files and ownership

Modify `src/booth.js`, `src/index.js`, `src/notification.js`, `test/booth.test.js` and `test/notification.test.js` under the Worker. Runs after BE-01 and BE-02; FE-02 does not modify Worker files.

## Deliverables

1. `POST /auth/booth/send` requires a valid staff kiosk session and unexpired, approved booth context; it re-reads the live, unique registration match and derives both the report path and email **only on the server**, not from a new email submitted at Finish.
2. Issue the report-bound event link from BE-02, send through approved mail infrastructure and reject an unrelated/personal address when the signed-off policy requires it.
3. Deduplicate repeat taps without falsely claiming delivery; return explicit failure for disabled event, send error and missing template.
4. Test that no user-supplied `path` or alternate recipient can change the send target; never log raw emails or tokens.

Run `cd workers/cloudflare/cug-adobe-oauth-worker && npx vitest run test/booth.test.js test/notification.test.js test/sharelink.test.js` and `npx eslint src/booth.js src/index.js src/notification.js test/booth.test.js test/notification.test.js`, followed by `git diff --check`. Done means delivery succeeds to the roster address or clearly fails; unrelated staff sharing remains unchanged.

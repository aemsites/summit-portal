01 · The experience

From registration email to a sales conversation.

Before attendees arrive, staff sign in and choose the active event using a setup link. The touchscreen then stays on one clean /booth page. A registered email opens the existing report directly; a booth-only Finish control brings the attendee back.

Touchscreen journey

A guided, interactive conversation.

  1. Enter the registration emailThe attendee uses the email address submitted during event registration.
  2. Open the existing reportA match takes the browser straight to the prepared portal-landing page, without a confirmation screen.
  3. Explore, then tap FinishThe same report has a booth-only return control so the attendee can move to the final step.
  4. Handle a missing matchA booth expert checks the address against the registration list. The portal never opens a different company’s report.

Finish the session

Turn the insight into a next step.

  1. Return to the booth pageFinish opens the final view of the same reusable page, not an event-specific site.
  2. Email the reportSend a secure link to the same registered address so the attendee can revisit it later.
  3. Talk to the booth teamOn-screen text suggests asking for a sales introduction or a later 1:1; these are not booking buttons.
  4. Reset the screenFinish the session and return to the welcome page for the next attendee.

03 · What changes

A focused set of improvements.

We are adapting the existing portal into a reusable event experience, without building scanner integration or separate pages for each event.

Portal design Create a question-led, motion-optional booth welcome that draws attendees in before showing the prepared-report email action. Motion pauses during entry and respects reduced-motion settings. Keep the normal portal entry and login flow unchanged.
Booth setup Staff sign in once and select the event with a staff-only setup link. The event selection stays on the device; the attendee sees only the clean, reusable /booth page.
Booth access Match a registered attendee’s email and navigate directly to the prepared portal-landing page, with no extra company confirmation screen.
Example report Keep the public Frescopa asset for a staff-led demonstration if useful, not as a competing report screenshot or link on the attendee Entry. A future kiosk link requires approval and a safe way back to the booth.
Learn-more QR Consider the existing static QR asset for separate booth signage, clearly labeled as the Adobe Brand Visibility product website for a visitor’s phone. It is not on the current Entry or Finish concept. Company reports still open through registration email; this is not badge scanning or report access.
Report return Show a booth-only Finish control on the existing report page. It returns to the final view on the same reusable booth page; no per-report edits.
Attendee preparation Load and validate the final Name, Company and Email registration list before the event.
Report delivery Email a secure report link at the end of the booth session so the attendee can revisit it later.
Touchscreen support Review and adapt report landing pages so they read and behave well on the 40-inch portrait touchscreen.
Sales handoff Make the in-person Adobe-team introduction visually prominent after the report, but non-interactive until there is a named owner, available salesperson, fallback and booking destination. Keep report email as the confirmed action and reset quiet but accessible.
Branding Use the same reusable experience with an Adobe or Semrush presentation, selected for the event without creating a bespoke page.
Shared-device access Entering a registered email identifies a prepared report but does not verify the attendee’s identity. The event team must agree how the staffed touchscreen is managed.

05 · Who does what

Clear ownership keeps it simple.

The experience depends on an accurate registration list, prepared reports, working screen equipment and a clear sales path.

Digital Insights

Prepare access

  • Match registration emails to reports
  • Flag missing reports before the event
  • Prepare report email delivery
  • Configure the agreed brand presentation and event setup

Event team

Prepare the event

  • Provide the final Name, Company and Email list
  • Tell attendees to use their registration email
  • Confirm Adobe or Semrush branding
  • Prepare the booth bookmark, browser device and internet access

Booth experts

Guide the conversation

  • Help attendees enter their registration email
  • Walk through the report
  • Explain the most important opportunities
  • Connect attendees with sales or a later meeting
